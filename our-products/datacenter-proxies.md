# Датацентр прокси

<mark style="color:purple;">Датацентр прокси</mark> представляют собой прокси для высоконагруженных сценариев и задачи, как правило размещаются на хостингах, обладают самый высокой скоростью и стабильностью.

<mark style="color:purple;">Прокси Датацентр</mark> как и <mark style="color:purple;">ISP</mark> выдаются в одни руки, никакого шейринга (больше одного пользователя за адресом) и другой формы обмана. Адреса относятся к типу <mark style="color:purple;">IPv4</mark> и также имеют поддержку <mark style="color:purple;">UDP</mark>.

{% embed url="https://dashboard.proxyshard.com/en/datacenter-proxy" %}

## Характеристики

| Параметр            | Значение                                                                  |
| ------------------- | ------------------------------------------------------------------------- |
| Тип IP              | IPv4                                                                      |
| Шеринг              | Нет — один IP на одного пользователя                                      |
| Лимит подключений   | 2 500 на IP                                                               |
| Поддержка UDP       | ✓                                                                         |
| Поддержка p0f       | ✓ (при аренде от месяца, +$0.3 / IP)                                     |
| Стоимость           | **$0.3** / 3 дня · **$0.4** / нед. · **$0.7** / полм. · **$1.2** / мес. |

## Описание полей заказа

Рассмотрим поля <mark style="color:purple;">Заказа</mark>:

<figure><img src="../.gitbook/assets/image (67).png" alt=""><figcaption></figcaption></figure>

<mark style="color:purple;">User ID</mark> - Это User используется для внутренней идентификации вашего заказа, иногда мы его запрашиваем при обращении в техническую поддержку.

<mark style="color:purple;">Status</mark> - Статус заказа, может иметь статусы:

* <mark style="color:green;">**Active**</mark> - Активный заказ
* <mark style="color:orange;">**On-Hold**</mark> - Ожидание оплаты заказа при истечении срока аренды
* <mark style="color:red;">**Cancelled**</mark> - Отменённый заказ

{% hint style="danger" %}
Восстановлению заказы со статусом "<mark style="color:$danger;">**Cancelled**</mark>" после трех дней с момента окончания аренды **невозможна**.
{% endhint %}

<mark style="color:purple;">Price</mark> - Стоимость продукта в месяц

<mark style="color:purple;">Username</mark> - Логин прокси

<mark style="color:purple;">Password</mark> - Пароль прокси

<mark style="color:purple;">Next Due Date</mark> - Следующая дата списания

<mark style="color:purple;">Copy proxy</mark> - Кнопка для копирования прокси в буфер обмена

<mark style="color:purple;">HTTP/SOCKS</mark> - Выбор типа протокола прокси

<mark style="color:purple;">Re-generate</mark> - Смена пароля на прокси

<mark style="color:purple;">Auto renew</mark> - переключатель для активации/деактивации продления продукта каждый месяц <mark style="color:purple;">(средства списываются с баланса аккаунта в срок, указанный при приобретении)</mark>

## Для каких задач подходит

Большинство криптобирж, Polymarket и площадки, массовый web scraping простых сайтов, быстрый сбор публичных данных, мониторинг доступности и uptime checks, SEO scraping, price monitoring на слабо защищённых сайтах, нагрузочное тестирование собственных систем, парсинг каталогов и справочников, автоматизация API запросов.

## Плюсы и минусы Датацентр прокси

#### <mark style="color:green;">Плюсы:</mark>

* **Широкий канал в Tier 4 ЦОД** с минимально возможной задержкой
* **Статические адреса в одни руки** — IP не меняется на протяжении аренды
* **Поддержка p0f и UDP**
* **Низкая цена** — самый доступный вариант среди всех продуктов
* **Гибкие сроки аренды** — от 3 дней до месяца
* **Высокая стабильность и доступность**

#### <mark style="color:red;">Минусы:</mark>

* **Легко определяются** — в крупных геолокационных базах стоит пометка DC / Hosting, это норма и мы её не скрываем
* **Не подходит для ряда платформ** — некоторые ресурсы прямо блокируют DC-адреса (например, DePIN-проекты Grass и Gradient)

{% hint style="success" %}
Данные ограничения обходятся [ISP прокси](isp-proxies.md)
{% endhint %}
