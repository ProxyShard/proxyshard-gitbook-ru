# Датацентр прокси

<mark style="color:purple;">Датацентровые прокси</mark> предназначены для высоконагруженных задач. Они размещаются в дата-центрах и обеспечивают максимальную скорость и стабильность.

<mark style="color:purple;">Датацентровые прокси</mark>, как и <mark style="color:purple;">ISP</mark>, выдаются одному пользователю без скрытого шейринга. Адреса относятся к типу <mark style="color:purple;">IPv4</mark> и поддерживают <mark style="color:purple;">UDP</mark>.

Пошаговая инструкция по покупке и оплате: [Приобретение ISP / Datacentre](../site-navigation/buying-and-renewing/buying-datacenter-proxies.md).

## Характеристики

| Параметр            | Значение                                                                  |
| ------------------- | ------------------------------------------------------------------------- |
| Тип IP              | IPv4                                                                      |
| Шеринг              | Нет - один IP на одного пользователя                                      |
| Лимит подключений   | 2 500 на IP                                                               |
| [Поддержка UDP](about-udp/) | ✓                                                                  |
| [Поддержка p0f](p0f-spoofing.md) | ✓ (при аренде от месяца, +$0.3 / IP)                         |
| Стоимость           | **$0.3** / 3 дня · **$0.4** / нед. · **$0.7** / полм. · **$1.2** / мес. |

## Как приобрести

1. Откройте раздел `Datacenter Proxy`.
2. В поле `Proxy region` выберите страну.
3. В поле `Billing cycle` выберите срок аренды.
4. В поле `Number of proxies` укажите количество прокси.
5. Включите `Auto renew`, если заказ нужно продлевать автоматически.
6. При необходимости включите `Enable p0f settings`.
7. В поле `Total slots` укажите, для скольких прокси нужна подмена p0f.
8. Если у вас есть промокод, введите его в поле `Promocode` и нажмите `Apply`.
9. Проверьте стоимость и нажмите `Buy now`.

## Поля заказа

<figure>
  <picture>
    <source srcset="../.gitbook/assets/datacenter-order-details_black.png" media="(prefers-color-scheme: dark)">
    <img src="../.gitbook/assets/datacenter-order-details_white.png" alt="Поля заказа датацентр-прокси">
  </picture>
</figure>

* `Status` показывает состояние заказа: `Active`, `On-hold` или `Canceled`.
* `Product tag` задаёт метку для поиска заказа в списках.
* `User ID` используется для внутренней идентификации заказа и может потребоваться при обращении в поддержку.
* `Proxy Region` показывает выбранную страну.
* `p0f slots` показывает количество активных слотов p0f и их изменение в следующем платёжном периоде.
* `Username` и `Password` содержат данные авторизации. Кнопка `Regenerate` создаёт новый пароль, после чего старые строки подключения перестают работать.
* `Billing cycle`, `Next due date`, `Price` и `Next charge` показывают срок аренды и данные следующего платежа.
* `Auto-renew proxy` управляет автоматическим продлением. Те же настройки доступны через `Manage renewal`.
* Кнопки `p0f` и `Buy p0f slots` открывают настройки подмены отпечатка и покупку дополнительных слотов.
* В блоке `Proxy List` можно выбрать `HTTP` или `SOCKS5`, изменить формат строки, скопировать список через `Copy all` или выгрузить его через `Export All`.

{% hint style="danger" %}
Заказ со статусом `Canceled` восстановить нельзя. Этот статус присваивается через три дня после неоплаты.
{% endhint %}

## Для каких задач подходит

Большинство криптобирж, Polymarket и площадки, массовый web scraping простых сайтов, быстрый сбор публичных данных, мониторинг доступности и uptime checks, SEO scraping, price monitoring на слабо защищённых сайтах, нагрузочное тестирование собственных систем, парсинг каталогов и справочников, автоматизация API запросов.

## Плюсы и минусы Датацентр прокси

#### <mark style="color:green;">Плюсы:</mark>

* **Широкий канал в Tier 4 ЦОД** с минимально возможной задержкой
* **Статические адреса в одни руки** - IP не меняется на протяжении аренды
* **Поддержка p0f и UDP**
* **Низкая цена** - самый доступный вариант среди всех продуктов
* **Гибкие сроки аренды** - от 3 дней до месяца
* **Высокая стабильность и доступность**

#### <mark style="color:red;">Минусы:</mark>

* **Легко определяются** - в крупных геолокационных базах стоит пометка DC / Hosting, это норма и мы её не скрываем
* **Не подходит для ряда платформ** - некоторые ресурсы прямо блокируют DC-адреса (например, DePIN-проекты Grass и Gradient)

{% hint style="success" %}
Данные ограничения обходятся [ISP прокси](isp-proxies.md)
{% endhint %}
