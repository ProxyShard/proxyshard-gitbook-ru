# Standard Residential

<mark style="color:purple;">Standard Residential</mark> - базовый пул резидентских прокси ProxyShard. Прокси размещены на реальных домашних устройствах, прошедших стандартные фильтры отбора. Поддерживают <mark style="color:purple;">UDP</mark>, что делает их оптимальным выбором для задач с <mark style="color:purple;">WebRTC</mark>.

{% embed url="https://dashboard.proxyshard.com/en/residential-main" %}

Пошаговая инструкция по покупке и оплате: [Приобретение резидентских прокси](../../site-navigation/buying-and-renewing/buying-residential-proxies.md).

## Характеристики

| Параметр                    | Значение                       |
| --------------------------- | ------------------------------ |
| Размер пула                 | 300 000 - 400 000 устройств    |
| Макс. кол-во соединений     | 35 000                         |
| Макс. скорость на заказ     | 75 Mbps                        |
| [Поддержка UDP](../about-udp/) | ✓ (кроме США; есть ограничения по портам) |
| [Фильтрация Device OS](../p0f-spoofing.md) | ✗ |
| Тарификация                 | За гигабайты (система Pay as you go) |
| Стоимость                   | **$2 / ГБ**                          |

## Для каких задач подходит

- Автоматизация, парсинг, боты
- Мультиаккаунтинг с антидетект-браузерами
- Задачи, требующие поддержки <mark style="color:purple;">UDP / WebRTC</mark>
- Работа с платформами, блокирующими датацентровые IP

{% hint style="info" %}
Нужно убрать ограничение по трафику? Смотрите [Unlimited Residential](unlimited-residential-proxy.md) - тот же пул, но без учёта гигабайтов.\
Нужен максимально крупный и чистый пул? Смотрите [Premium Residential](premium-residential.md).
{% endhint %}
