# Реферальная программа

У каждого клиента есть возможность заработать с помощью реферальной программы. 

Во вкладке "<mark style="color:purple;">Affiliate</mark>" находится реферальная ссылка. С её помощью можно приглашать друзей и знакомых на сайт.

Система реферального вознаграждения работает следующим образом:

<figure><img src="../.gitbook/assets/image (253).png" alt=""><figcaption></figcaption></figure>

За каждую покупку на сайте приводимым лицом, вы получаете <mark style="color:purple;">**10%**</mark>. 

Также у вас есть возможность указать личную ссылку реферала. \
Для этого нажмите "<mark style="color:purple;">Edit</mark>" возле ссылки и измените на ваше значение.

<figure><img src="../.gitbook/assets/image (254).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Информация о переходах по ссылке и информация по начисленным средствам не раскрывается при запросе в техническую поддержку
{% endhint %}
