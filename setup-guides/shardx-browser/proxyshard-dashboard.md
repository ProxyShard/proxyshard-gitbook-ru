# ProxyShard Dashboard

Раздел <mark style="color:purple;">**ProxyShard**</mark> подключает ваш аккаунт [ProxyShard](https://proxyshard.com) к приложению: баланс, трафик, заказы и покупка прокси доступны прямо в ShardBrowser.

Чтобы подключить аккаунт, скопируйте API-ключ на [вкладке API Key в личном кабинете ProxyShard](https://dashboard.proxyshard.com/en/profile?tab=api-key) и вставьте его в поле блока <mark style="color:purple;">**Connect your ProxyShard account**</mark>.

  </picture>

Нажмите <mark style="color:purple;">**Save**</mark>.

{% hint style="info" %}
API-ключ хранится на вашем компьютере и отправляется только в ProxyShard. Не передавайте его посторонним.
{% endhint %}

После подключения откроется панель аккаунта:

- **Residential** - остаток трафика резидентных прокси, кнопки <mark style="color:purple;">**Buy traffic**</mark> и <mark style="color:purple;">**Generate proxies**</mark>
- **Balance** - баланс аккаунта
- **Active orders** - количество активных заказов
- **Usage** - график израсходованного трафика и число запросов за выбранный период, а также неудачные запросы (<mark style="color:purple;">**Failed requests**</mark>)
- **Orders** - список заказов с продуктом, номером заказа, сроком действия и тегом

Кнопка <mark style="color:purple;">**Buy proxies**</mark> открывает покупку прокси, <mark style="color:purple;">**Open dashboard**</mark> - личный кабинет на сайте.
