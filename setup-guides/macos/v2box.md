## Настройка прокси соединения

Из заказа скопируйте подключение в соответствующие поля (IP/Hostname:PORT:USERNAM:PASSWORD) и нажмите ![](<../../.gitbook/assets/image (90).png>). В "<mark style="color:purple;">Remark</mark>" можно указать произвольное имя профиля

<figure><img src="../../.gitbook/assets/Image00004 (1).PNG" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**С примером настройки прокси вы можете ознакомиться в разделе [Инструкция по настройке](../getting-started.md)**
{% endhint %}
