# iOS / Android

## Программы для настройки прокси на iOS / Android

### [<mark style="color:purple;">**V2Box**</mark>](v2box.md)

* Платформа: <mark style="color:purple;">iOS</mark>, <mark style="color:purple;">Android, MacOS</mark>
* Поддержка UDP: Да
* Сложность: Средняя
* Раздельная маршрутизация: Появилась в последних обновления

### [<mark style="color:purple;">**Potatso**</mark>](potatso.md)

* Платформа: <mark style="color:purple;">iOS</mark>
* Поддержка UDP: Да
* Сложность: Легкая
* Раздельная маршрутизация: нет, полное туннелирование

### [<mark style="color:purple;">**SuperProxy**</mark>](super-proxy.md)

* Платформа: <mark style="color:purple;">Android</mark>
* Поддержка UDP: Да
* Сложность: Легкая
* Раздельная маршрутизация: нет, полное туннелирование
