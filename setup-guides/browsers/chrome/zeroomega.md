# ZeroOmega

## Установка ZeroOmega

{% hint style="warning" %}
ZeroOmega работает только с TCP-трафиком. Для работы с UDP используйте [Vision Browser](../../antidetect-browsers/vision-browser.md).
{% endhint %}

Установите [ZeroOmega](https://chromewebstore.google.com/detail/pfnededegaaopdmhkdmcofjmoldfiped) из Chrome Web Store.

{% embed url="https://chromewebstore.google.com/detail/pfnededegaaopdmhkdmcofjmoldfiped" %}

После установки откройте меню расширений и закрепите ZeroOmega на панели браузера.

<figure><img src="../../../.gitbook/assets/chrome-extensions-pin-zeroomega.png" alt="Закрепление ZeroOmega на панели Chrome"><figcaption></figcaption></figure>

Откройте ZeroOmega и выберите `Параметры`.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-open-options_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-open-options_white.png" alt="Открытие настроек ZeroOmega">
  </picture>
</figure>

## Настройка прокси

В разделе профилей нажмите `Новый профиль...`.

<div align="center"><figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-new-profile_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-new-profile_white.png" alt="Создание профиля ZeroOmega">
  </picture>
</figure></div>

Введите название профиля, выберите `Профиль прокси` и нажмите `Создать`.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-new-profile-dialog_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-new-profile-dialog_white.png" alt="Название и тип профиля ZeroOmega">
  </picture>
</figure>

В настройках профиля выберите протокол и укажите адрес сервера и порт из `Proxy List` вашего заказа. Чтобы добавить логин и пароль, нажмите значок замка.

{% hint style="info" %}
Формат данных и пример заказа описаны в разделе [Начало работы](../../getting-started.md).
{% endhint %}

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-proxy-server_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-proxy-server_white.png" alt="Адрес и порт прокси в ZeroOmega">
  </picture>
</figure>

Введите логин и пароль прокси, затем нажмите `Сохранить изменения`.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-proxy-auth_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-proxy-auth_white.png" alt="Авторизация прокси в ZeroOmega">
  </picture>
</figure>

Нажмите `Применить изменения`, чтобы сохранить профиль.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/chrome-zeroomega-apply-changes_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/chrome-zeroomega-apply-changes_white.png" alt="Сохранение профиля ZeroOmega">
  </picture>
</figure>

Откройте ZeroOmega на панели браузера и выберите созданный профиль.

<figure><img src="../../../.gitbook/assets/chrome-zeroomega-select-profile.png" alt="Выбор профиля ZeroOmega"><figcaption></figcaption></figure>

Прокси подключён и готов к работе в Chrome.
