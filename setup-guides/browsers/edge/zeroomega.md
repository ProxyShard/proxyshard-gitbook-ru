# ZeroOmega

## Установка ZeroOmega

{% hint style="warning" %}
ZeroOmega работает только с TCP-трафиком. Для работы с UDP используйте [Vision Browser](../../antidetect-browsers/vision-browser.md).
{% endhint %}

Установите [ZeroOmega](https://microsoftedge.microsoft.com/addons/detail/proxy-switchyomega-3-zer/dmaldhchmoafliphkijbfhaomcgglmgd) из Microsoft Edge Add-ons.

{% embed url="https://microsoftedge.microsoft.com/addons/detail/proxy-switchyomega-3-zer/dmaldhchmoafliphkijbfhaomcgglmgd" %}

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-addons-get_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-addons-get_white.png" alt="Установка ZeroOmega в Microsoft Edge">
  </picture>
</figure>

После установки откройте меню расширений и закрепите ZeroOmega на панели браузера.

<figure><img src="../../../.gitbook/assets/edge-extensions-pin-zeroomega.png" alt="Закрепление ZeroOmega на панели Microsoft Edge"><figcaption></figcaption></figure>

## Настройка ZeroOmega

Откройте ZeroOmega и выберите `Options`.

<figure><img src="../../../.gitbook/assets/edge-zeroomega-popup-options.png" alt="Открытие настроек ZeroOmega"><figcaption></figcaption></figure>

В разделе `Profiles` нажмите `New profile...`.

<div align="center"><figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-new-profile_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-new-profile_white.png" alt="Создание профиля ZeroOmega">
  </picture>
</figure></div>

Введите название профиля, выберите `Proxy Profile` и нажмите `Create`.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-new-profile-dialog_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-new-profile-dialog_white.png" alt="Название и тип профиля ZeroOmega">
  </picture>
</figure>

В настройках профиля выберите протокол и укажите адрес сервера и порт из `Proxy List` вашего заказа. Чтобы добавить логин и пароль, нажмите значок замка.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-proxy-server_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-proxy-server_white.png" alt="Адрес и порт прокси в ZeroOmega">
  </picture>
</figure>

Введите логин и пароль прокси, затем подтвердите изменения.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-proxy-auth_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-proxy-auth_white.png" alt="Авторизация прокси в ZeroOmega">
  </picture>
</figure>

{% hint style="info" %}
Формат данных и пример заказа описаны в разделе [Начало работы](../../getting-started.md).
{% endhint %}

Нажмите `Apply changes`, чтобы сохранить профиль.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-apply-changes_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-apply-changes_white.png" alt="Сохранение профиля ZeroOmega">
  </picture>
</figure>

Откройте ZeroOmega на панели браузера и выберите созданный профиль.

<figure>
  <picture>
    <source srcset="../../../.gitbook/assets/edge-zeroomega-select-profile_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../../.gitbook/assets/edge-zeroomega-select-profile_white.png" alt="Выбор профиля ZeroOmega">
  </picture>
</figure>

Прокси подключён и готов к работе в Microsoft Edge.
