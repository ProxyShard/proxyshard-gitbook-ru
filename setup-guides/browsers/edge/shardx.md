# ShardX Extension

Наше фирменное расширение <mark style="color:purple;">**ShardX – Smart Proxy Manager**</mark> работает в Microsoft Edge без ограничений, он построен на движке Chromium и поддерживает расширения из **Chrome Web Store**.

{% hint style="info" %}
При первой установке расширения из Chrome Web Store Edge может предложить «**Разрешить расширения из других магазинов**», подтвердите это разрешение.
{% endhint %}
