# ShardX Extension

Наше фирменное расширение <mark style="color:purple;">**ShardX – Smart Proxy Manager**</mark> устанавливается в Opera напрямую из **Chrome Web Store**.

## Установка

Откройте страницу расширения и нажмите кнопку установки. Если Opera запросит подтверждение установки расширения из Chrome Web Store, подтвердите его.
