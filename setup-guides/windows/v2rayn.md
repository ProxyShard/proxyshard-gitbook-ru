# v2rayN

{% hint style="success" %}
Данное решение поддерживает туннелирование по UDP!
{% endhint %}

## Настройка v2rayN

Перейдите по [ссылке](https://github.com/2dust/v2rayN/releases/latest) для загрузки <mark style="color:purple;">v2rayN</mark> и распакуйте архив на рабочем столе.

{% embed url="https://github.com/2dust/v2rayN/releases/latest" %}

<figure><img src="../../.gitbook/assets/Image00001 (5).PNG" alt=""><figcaption></figcaption></figure>

## **Создание профиля**

Создайте новую конфигурация указав <mark style="color:purple;">SOCKS / HTTP</mark> в качестве протокола подключения

<figure><img src="../../.gitbook/assets/Image00002 (7).PNG" alt=""><figcaption></figcaption></figure>

## Настройка профиля подключения

Скопированные прокси из заказа вставьте в соответствующие поля, обязательно укажите ядро конфигурации (Xray/SingBox) и сохраните настройки.

<figure><img src="../../.gitbook/assets/Image00003 (6).PNG" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**С примером настройки прокси вы можете ознакомиться в разделе** [**Инструкция по настройке**](../getting-started.md)
{% endhint %}

## Запуск клиента

Запустите клиент, включив <mark style="color:purple;">Tun</mark> режим.

<figure><img src="../../.gitbook/assets/Image00004 (7).PNG" alt=""><figcaption></figcaption></figure>

**Готово! Теперь вы можете полноценно использовать прокси, туннелируя весь трафик через прокси.**
