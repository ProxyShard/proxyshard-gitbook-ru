# NekoRay

{% hint style="success" %}
Данное решение поддерживает туннелирование по UDP!
{% endhint %}

## Настройка **NekoRay.**

Перейдите по [ссылке](https://github.com/MatsuriDayo/nekoray/releases) для загрузки программы

{% embed url="https://github.com/MatsuriDayo/nekoray/releases" %}

## **Добавление профиля Nekoray**

В пустом поле программы нажмите правую клавиши мыши для вызова контекстного меню и создайте новый профиль

<figure><img src="../../.gitbook/assets/Image00002 (6).PNG" alt=""><figcaption></figcaption></figure>

## Установка прокси-сервера в профиль Nekoray

В окне создании профиля подключения, укажите протокол подключения "<mark style="color:purple;">Socks</mark>" или "<mark style="color:purple;">HTTP</mark>"

<figure><img src="../../.gitbook/assets/image (23) (1).png" alt=""><figcaption></figcaption></figure>

Установите параметры подключения к прокси исходя из вашего [заказа](https://dashboard.proxyshard.com/products)

{% hint style="info" %}
**С примером настройки прокси вы можете ознакомиться в разделе [Инструкция по настройке](../getting-started.md)**
{% endhint %}

<figure><img src="../../.gitbook/assets/image (24) (1).png" alt=""><figcaption></figcaption></figure>

## Начало работы

Установите '<mark style="color:purple;">TUN Mode</mark>' и запустите созданный профиль кликну в правой кнопкой по нему и нажав '<mark style="color:purple;">Start</mark>'

<figure><img src="../../.gitbook/assets/Image00004 (6).PNG" alt=""><figcaption></figcaption></figure>

**Готово! Теперь вы можете полноценно использовать прокси, туннелируя весь трафик на прокси.**
